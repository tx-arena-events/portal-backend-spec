# C1-M1 PSP Admission

**Version:** dropped, as of 2026-10-28
**Capability:** C1 Onboarding
**Kind:** dropped with OSP 2.0

With OSP 2.0, there is no longer a central portal core at which PSPs are admitted. An OSP runs its own installation.

**Where the tasks went:** The governance of the dataspace rules the admission of an OSP; the CSP enters the OSP in the trust list (FRAMEWORK 5.1). In the installation, the settings hold only the OSP's own `ospId` (FRAMEWORK 4.8); C3-M2 CSP Connection handles the connection to the CSP.
